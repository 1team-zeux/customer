장애 주입

시나리오 1 — DB 응답 지연 OFF
inventory-service 내부에서 Thread.sleep(5000) 주입.
주문 요청 후 5초 이상 소요 → Latency 스파이크 → 알림 발생
시나리오 2 — DB 연결 오류 OFF
inventory-service에서 RuntimeException 발생.
HTTP 500 연쇄 → 주문 FAILED → Error Rate 알림 발생
시나리오 3 — 추천 에이전트 다운
터미널에서 직접 실행:
docker stop recommendation-agent

주문은 정상 처리됨 (graceful degradation, 빈 추천 반환).
약 3분 후 RecommendationAgentDown 알림 발생.
시나리오 4 — CPU 폭주 (30초)
order-service에서 가상 스레드 스핀 30초 실행.
jvm_cpu_usage 80% 초과 → ServiceCpuSpike 알림
